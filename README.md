# 🖼️ Zen Wallpaper Collection

A personal collection of wallpapers curated by **zenyxsa**.

This repository contains a mix of wallpapers collected around different themes and aesthetics — from **anime and cars** to scenic, minimal, gaming, and other visually interesting wallpapers.

## ✨ Collection

* 🌸 **Anime** — characters, scenes, artwork & aesthetics
* 🏎️ **Cars** — automotive, JDM, supercars & racing
* 🌌 **Aesthetic** — atmospheric and visually striking wallpapers
* 🎮 **Gaming** — game-inspired wallpapers
* 🌆 **Scenery** — landscapes, cities & environments
* 🖤 **Miscellaneous** — other wallpapers that fit the collection

## 📥 Clone the Collection

Clone the repository with Git:

```bash
git clone https://github.com/zenyxsa/Zen-Wallpaper-Collection.git
```

Then enter the directory:

```bash
cd Zen-Wallpaper-Collection
```

The wallpapers are available in:

```text
Zen-Wallpaper-Collection/
└── Wallpapers/
```

### 🐧 Linux

For Linux users, you can also clone directly into your Pictures directory:

```bash
git clone https://github.com/zenyxsa/Zen-Wallpaper-Collection.git ~/Pictures/Zen-Wallpaper-Collection
```

### 🔄 Update the Collection

If you already cloned the repository, update it with:

```bash
cd Zen-Wallpaper-Collection
git pull
```

New wallpapers added to the repository can then be found inside the `Wallpapers/` directory.
